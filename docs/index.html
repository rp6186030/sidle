Four controls, zero new habits

A gesture starts only when one finger rests on an edge and you physically click. Palms, typing and scrolling never trigger it.

Right edge

Volume

Slide up or down. Same steps as the volume keys, with the real macOS indicator.

Left edge

Brightness

Slide to dim or brighten the built-in display. Swap sides if you prefer.

Bottom edge

Seek

Slide sideways and release to jump through a video or song, with a live preview.

Top corners

Buttons

One to four clicks each. Mute, launch an app, run a Shortcut, press any hotkey.

Tuned to feel like hardware

Haptic ticks

Every step clicks under your finger through the Force Touch trackpad.

Pointer stays put

The cursor freezes while you slide and is right where you left it on release.

Measured in millimetres

A slide feels the same on a MacBook and a Magic Trackpad.

Fine control

Hold ⇧⌥ while sliding for quarter steps.

Corners that do what you want

Each top corner takes up to four actions, one per click count. A corner with nothing assigned stays a normal part of the trackpad.

Open or hide an app

Click to bring it forward, click again to hide it.

Open a link

A web page, a folder, a file or an app link.

Press a shortcut

Screenshot, Mission Control, lock screen, or any hotkey you already use.

Run a Shortcut

Anything the Shortcuts app can do, from a Focus mode to a script.

Install

Homebrew

brew install --cask rp6186030/sidle/sidle

Or download

Get the latest zip, unzip, and move Sidle to Applications.

First launch

Sidle is not notarized, because that needs a paid Apple Developer account. Run this once so macOS will open it:

xattr -dr com.apple.quarantine /Applications/Sidle.app

Or open it, then choose Open Anyway in System Settings → Privacy & Security. Then grant Accessibility when asked.

Questions

Why does it need Accessibility?

To press the volume and brightness keys for you, press your corner shortcuts, and keep clicks on the edge out of other apps. Sidle never records what you type.

Does anything leave my Mac?

No touch data ever does. The only network request is a once-a-day check of the GitHub release page for a new version.

Why isn't it on the Mac App Store?

Sidle reads finger positions through Apple's private MultitouchSupport framework, which App Store apps may not use. The source is public so you can see exactly what it does.

Why does macOS warn me when I open it?

Notarization requires a paid Apple Developer membership. Sidle is free, so it ships unsigned by Apple. You can read the code and build it yourself with one command.

Which trackpads work?

The built-in Force Touch trackpad and the Magic Trackpad. With two connected, the one you touch is in charge.

Will it get in the way of normal clicks?

Only clicks that land inside the thin edge strip start a gesture, and you can require a modifier key or shrink the strip in Settings.
