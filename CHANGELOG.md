## 1.0.0

First public release.

- Right edge volume, left edge brightness, bottom edge media seek with preview.
- Top-corner actions for 1 to 4 clicks: mute, open/hide app, open link, keyboard shortcut, run a Shortcut, play/pause, Mission Control, lock screen.
- Settings for edge width, sensitivity, swap sides, modifier key, bottom-quarter-only, haptics, launch at login.
- Daily update check against GitHub Releases.
